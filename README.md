# Currency Converter

A simple Python terminal application that fetches live exchange rates (USD, EUR, GBP) and converts selected currencies to TRY using a free API.

I built this project to practice working with REST APIs, parsing JSON data, and handling user choices in Python.

## Features
- Fetches live USD/TRY, EUR/TRY, and GBP/TRY exchange rates
- Interactive menu to convert USD, EUR, or GBP to TRY
- Simple error handling for network issues and invalid inputs

## Requirements
- Python 3.x
- `requests` library
